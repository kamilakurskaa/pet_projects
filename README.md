### 1. A/B-тест нового алгоритма рекомендаций

**A/B-тестирование / Статистика**

Анализ эксперимента по внедрению нового алгоритма рекомендаций.

**Что сделала:**

* определил ключевую метрику — долю успешных сессий
* проверила баланс экспериментальных групп
* сформулировала статистические гипотезы
* провела статистический тест
* интерпретировала статистическую и практическую значимость результата
* сформулировала рекомендацию по результатам эксперимента

**Результат:** доля успешных сессий выросла с **30,77% до 31,83%**, абсолютный прирост составил **+1,06 %**, результат статистически значим.

**Стек:** Python, Pandas, NumPy, SciPy, Statsmodels, Matplotlib
